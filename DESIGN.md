# Design contract — native VLC Juxtopposed

## Задача и главный источник

Владелец попросил форкнуть **существующий** `dsojevic/vlc:juxtopposed-redesign`
и получить Windows-сборку/установщик. Это не заказ новой дизайн-системы и не
перевёрстка по мотивам. Главный источник — исходные Qt/QML компоненты этой
ветки; Figma/видео являются атрибуцией/референсами, не отдельным заданием на Figma.

Токены: `modules/gui/qt/player/qml/redesign/RedesignTheme.qml`.
Каталог компонентов: соседние `Redesign*.qml`. SVG-пути — `RedesignIcon.qml`.
Автор оригинального дизайна — Juxtopposed, CC BY 4.0 (см. README.md).

## Границы изменений

Раскладка, SVG-пути, выбранная upstream типографика и палитра не перепроектируются.
Наши изменения — восстановление той же отрисовки на урезанной статической Qt
VLC: Basic Controls, native FolderModel, SVG вместо отключённого Canvas,
локальный SVG provider вместо неработающих data-URI запросов.

Индикатор громкости сохраняет исходные #6d9c00/#d4b400/#d37918, форму и
заполнение. Это функциональный сигнал уровня громкости, не новый акцент.
Новые шрифты/иконки/декоративные карточки не добавлялись.

## Явные исключения для существующей системы

- R1/R2/R3: используются исходный QML theme/каталог, не создаётся параллельный
  tokens.css/React/Storybook. Константы геометрии и исходные цвета в изменённом
  volume-компоненте сохранены от оригинала, не выбраны заново.
- R6: существующий выбор/наследование шрифта VLC не заменяется ради визуальной
  чистки. Inter агентом не вводится.
- R13/R15: сохраняются исходные тёмные поверхности и исходный единый SVG-набор;
  замена на Lucide/другую палитру противоречила бы запросу на копию.
- R26: цель — нативное Windows desktop приложение, не мобильная веб-страница.
  Не заявляется мобильный экран 390px. Проверяются реальные размеры окна,
  сворачивание панели, доступность управления и навигация.
- shot.mjs/measure.mjs и браузерные computed styles неприменимы: DOM отсутствует.
  Нет фиктивного HTML-клона для выдачи за нативный GUI. Проверка — настоящий
  Windows процесс, UIA дерево, окно и реальные PNG.

## Проверка

`review/player-native.png` — реальное окно сборки db6279df2c, только собственный
контент приложения, внешняя прозрачная рамка обрезана. `test-video.mp4` —
явно названное техническое H.264-видео FFmpeg, не выдуманная библиотека фильмов.

Проверены видимые SVG/volume и фактическое изменение UIA состояния библиотеки/
Play-Pause. Завершение процесса рассматривается отдельно от визуальной проверки;
ошибочная сборка с зависанием не выдаётся за готовую.

Итоговые UIA/установка/воспроизведение/закрытие и независимое ревью фиксируются
в TASK-STATE.md и review/. Скриншоты с системными окнами/личными уведомлениями
не публикуются. Изменения только технические, без косметического redesign-loop.
