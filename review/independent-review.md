## Замечания
**[Важно] `bin/winvlc.c:253` — нет `fflush(NULL)` перед `TerminateProcess`.**
- `TerminateProcess` не сбрасывает буферы CRT. Для `stderr` это не страшно, он небуферизован.
- `stdout` при перенаправлении буферизован. Вывод `--version`, `--help` или `-vvv > file` может пропасть.
- Вызов срабатывает и в ветке `vlc == NULL`.
- **Правка:** вставить `fflush(NULL);` строкой перед `TerminateProcess(...)`.

**[Важно] `bin/winvlc.c` — решение верное, но не проверено в работе.**
- **Порядок:** `libvlc_release`, затем `ReleaseCrashHandler`, затем `free(argv)`, затем `TerminateProcess`. Обращений к освобождённому после вызова нет.
- **Выбор вызова:**
  - `GetCurrentProcess()` с `TerminateProcess` допустим.
  - `_exit()` на MinGW всё равно уходит в `ExitProcess`, так что он не альтернатива.
  - `return 0` остаётся недостижимым fallback.
  - Exit code не меняется (0, как раньше).
  - `#ifdef __MINGW32__` покрывает и llvm-mingw.
- **Цена:**
  - `DLL_PROCESS_DETACH` не получает ни одна DLL, не только Qt.
  - Не выполняются atexit и статические деструкторы.
  - Из кода не видно, что пишется в обход `libvlc_release`.
  - Утверждение в комментарии «state persisted» и сам механизм deadlock (Qt-семафор, убитый peer) опираются на ваши данные по GetThreadContext. Из кода я их не проверил.
- **Что проверить после сборки:**
  - Процесс исчезает после Close, код 0.
  - Close срабатывает из всех путей: крестик, Alt+F4, Quit, tray. Проверить при play, pause и сразу после Open.
  - Настройки (громкость, окно, `vlc-qt-interface.ini`), media library и лог обновились.
  - Нет «призрачного» tray-значка.
  - Повторный запуск поднимает сохранённое состояние.
- Сам workaround ограничен frontend-ом (`bin/`), `libvlc.dll` не затронут.

**[Совет] `RedesignIcon.qml:56` — `color.toString()` при alpha < 1 даёт `#AARRGGBB`.**
- SVG-парсер ждёт `#RRGGBB` или `#RRGGBBAA`. Иконка с полупрозрачным цветом может стать пустой или неверной.
- Вызывающий код не читал. Возможно, prev/next затемнены через `opacity`, тогда проблемы нет.
- **Правка:** если есть вызовы с alpha, собирать `#rrggbb` из `r/g/b`, а прозрачность задавать через `Image.opacity`.

**[Совет] `RedesignIcon.qml:40` (`videos`) — `fill="#1b1b1b"` зашит и не следует теме.**
- В light theme вырез play-треугольника будет тёмным на тёмной заливке.
- **Правка:** свойство `cutoutColor` со значением по умолчанию `"#1b1b1b"`. Нужно, только если light theme достижима.
